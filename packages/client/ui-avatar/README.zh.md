# @deepseek-ai/dsh-client-ui-avatar

[English](README.md) | 中文

聊天头像插件（浏览器半区）：`ui-conversation` 聊天视图声明的 `conversation.avatar` 行头像座位。一个 occupant 同时渲染对话的双方——用户头像出现在每条用户/steering 气泡右侧（聊天惯例：自己的消息头像朝外），Agent 头像出现在每条助手叙述左侧。点击任意头像会打开「更换头像」弹窗：可上传图片（浏览器内裁剪压缩为 96×96 PNG）、选择带背景色的表情磁贴，或恢复默认头像。默认头像无需任何存储状态：用户侧是固定蓝色圆盘加本地化的「我」首字，每个 Agent 则用其会话 id 哈希出稳定色相，并取会话标题首字符作为字形——每个 Agent 一出现就有自己可区分的头像。

选择持久化在 `avatar` 设置命名空间中（`user` 字段 + 按会话 id 为键的 `agents` 映射），由本包的 node 半区通过 settings 接缝注册。所有头像表面共享同一个浏览器端设置作用域 store，任何一处的修改都会立即刷新所有行；远程浏览器的选择通过作用域的 memory 模式保持进程本地。上传图片压缩后以 data URL 存储，上限 96 KiB，以保持设置文档体积可控。

`/client` 导出为：插件主体（`apply`/`inject`）、`AvatarSurface` 组件、`AvatarSettingsStore`、注入面类型与头像领域类型。

## 模型体验

无：头像属于设置文档中的展示状态，任何头像数据都不进入追加式会话日志、模型上下文或遥测。

#### KV 缓存影响

无：头像变更不触及历史尾部。

## 已知限制与后续工作

- **仅聊天行**——头像座位由聊天视图条目声明，因此圆盘只出现在对话流中，会话列表与会话头部暂无头像；那些表面需要各自声明新的座位（一个座位只能由一个条目声明）。
- **导入后的图片一律为 PNG**——裁剪管线会把所有上传（包括动图格式）重编码为单帧 96×96 PNG。
- **写入失败只在弹窗内提示**——设置写入被拒时，错误行只显示在打开的弹窗中；弹窗关闭后无法提示后台失败。
